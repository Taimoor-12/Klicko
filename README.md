# Klicko — URL Shortener

A production-grade URL shortener built with a clean architecture backend and Next.js frontend.

## Tech Stack
**Backend:** Node.js, Express, TypeScript, PostgreSQL, Redis, BullMQ, Prisma
**Frontend:** Next.js 15, React, TypeScript, Tailwind CSS, shadcn/ui

## Project Structure
- `/backend` — Express REST API
- `/frontend` — Next.js frontend
